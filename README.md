# OAIAW — Online Assessment in the AI World

We are building an AI-native technical assessment platform where candidates solve realistic software engineering tasks inside a controlled development environment with an integrated AI coding agent.

## Project Structure
- `/frontend`: Next.js web application
- `/backend`: FastAPI service
- `/agent`: Python-based AI coding agent
- `/evaluator`: Service for assessing engineering evidence
- `/shared`: Shared libraries and types
- `/tasks`: Assessment task definitions
- `/docs`: Architecture and project documentation

## Running the Application
See the respective README files in `/frontend` and `/backend` for running the applications locally.
Docker compose can also be used for running infrastructure (PostgreSQL).
